# 八字（四柱、사주）

來源：《子平真詮》（月令取格）、《三命通會》、扶抑法。程式：`baziGeju`、`GEJU_RULE`、`yongShen`、`bzClash`、`baziFlows`、`tenGod`。

## 1. 旺衰

- 計日主得助（比劫、印）佔全局比例：天干每個 1 分（日干唔計）；地支藏干按本氣 1、中氣 0.5、餘氣 0.3，月支 ×2.5。比例 ≥ 50%＝身強，否則身弱。
- 藏干表：子癸；丑己癸辛；寅甲丙戊；卯乙；辰戊乙癸；巳丙戊庚；午丁己；未己丁乙；申庚壬戊；酉辛；戌戊辛丁；亥壬甲。

## 2. 月令取格（子平）

- 月支藏干本氣透干優先；否則取透出嘅中氣、餘氣；四庫無透就用本氣。
- 比肩＝建祿格；劫財＝陽干陽刃格、陰干月劫格；其餘按十神：正官格、七殺格、財格（正偏財）、印格（正偏印）、食神格、傷官格。

| 格 | 喜忌要點 |
|---|---|
| 正官格 | 最怕傷官同刑沖；喜財生官、印護官 |
| 七殺格 | 要有制有化：喜食神制殺、印化殺；最忌財黨殺 |
| 財格 | 喜食傷生財、官護財；最怕比劫分財 |
| 印格 | 喜官殺生印；最怕財壞印 |
| 食神格 | 喜生財；最怕偏印奪食 |
| 傷官格 | 喜生財或佩印；最忌見官 |
| 建祿格 | 身已有根，喜透官財食傷，忌再見比劫 |
| 月劫格 | 喜官殺制劫、財食流通，忌比劫重重 |
| 陽刃格 | 要官殺制服先成格，忌無制再見比劫 |

## 3. 喜忌（用神）

子平月令格局 65%＋扶抑 35%，得出五類十神（比劫、食傷、財、官殺、印）嘅喜忌分。

## 4. 流運

- 流日干支（干 1、支 0.5）、流月 0.5、流年 0.35、大運 0.3 加權。
- 刑沖合害、天干合；太歲（流年支沖或同年支）、天剋地沖（流年同日柱）、歲運並臨（流年同大運干支一樣）。
- 擇日亦會避開當日地支沖本命日支。
